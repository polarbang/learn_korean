# 공용 강조 에셋

영상 어디서나 쓰는 강조 표시. 손으로 그린 마커 느낌으로 **0.5초 동안 그려지고 1.5초 유지**된다.
미리보기: `preview.html`을 브라우저로 열기.

## 종류
**선 에셋** (각각 red / yellow / white / black — black은 밝은 배경용, 옅은 흰 테두리 포함)
| 파일 이름 | 모양 | 쓰는 곳 예시 |
|---|---|---|
| `circle` | 속이 빈 동그라미 (가로로 긴 타원) | 가격표 숫자, 진열대 위 물건 |
| `circle_round` | 속이 빈 원 (정원) | 아이콘, 한 글자, 작은 물건 |
| `rect` | 속이 빈 네모 | 자막 속 단어, 영수증 합계 |
| `underline` | 밑줄 | 자막의 타깃 단어 |
| `underline_double` | 두 줄 밑줄 (아랫줄이 더 김) | 특히 중요한 단어, 불규칙 활용 |
| `arrow` | 직선 화살표 (오른쪽) | 물건 가리키기 — 편집에서 회전해서 방향 조절 |
| `arrow_curved` | 휜 화살표 | 안내판, 화면 구석의 물건 |
| `check` | 체크 ✓ | 퀴즈 정답 |
| `cross` | 엑스 ✗ | 퀴즈 오답, "오늘은 안 사요!" |

**가리키는 손** (`hand_up` 하나, 색 구분 없음)
- Fluent Emoji 3D 손 (MIT, 출처 표기 불필요). 톡 튀어나온 뒤 가리키는 방향으로 두 번 콕콕 찌르고 멈춘다.
- 위를 가리키는 손 하나만 있음. 다른 방향은 CapCut에서 회전해서 쓴다.

**숫자** (`number_1` ~ `number_9`, 색 구분 없음)
- Fluent Emoji 3D 숫자 키캡 (MIT, 출처 표기 불필요). 0.25초 동안 톡 튀어나오며(살짝 커졌다가) 자리 잡고 유지된다.
- 쓰는 곳: 순서 표시(먼저 → 다음), 개수("세 개!"), 퀴즈 번호.

## 폴더
| 폴더 | 형식 | 언제 |
|---|---|---|
| `mov/` | ProRes 4444 (.mov), 투명 배경 | **CapCut에서 쓰는 파일** (투명 배경 확인됨) |
| `png/` | 완성된 정지 이미지 | 애니메이션 없이 그냥 띄울 때 |
| `_preview/` | VP9 (.webm) | `preview.html` 미리보기 전용. CapCut에서는 배경이 검게 나오니 쓰지 않는다 |

## 편집 팁
- 1.5초보다 오래 띄우려면 마지막 프레임을 늘리거나(프레임 고정) 같은 클립을 정지 이미지(`png/`)로 이어 붙인다.
- 크기·회전은 편집기에서 자유롭게. 선 두께도 같이 커지니 너무 크게 키우면 굵어 보인다.
- 사라질 때는 편집기에서 페이드 아웃(0.2초 정도)을 주면 자연스럽다.

## 다시 만들기 / 색·모양 추가
`make_overlays.py`의 `COLORS`(색), `STROKE`(두께), `DRAW_FRAMES`·`HOLD_FRAMES`(길이)를 바꾸고 실행한다.
```
pip install pillow imageio-ffmpeg
python make_overlays.py            # 전체
python make_overlays.py numbers    # 일부만 (lines / hands / numbers)
```
