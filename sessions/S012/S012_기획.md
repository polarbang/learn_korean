# S012 · 집에서 설거지하기 — 촬영 기획

- **주제**: 밥을 먹고 난 뒤 싱크대에 쌓인 그릇을 정리하고, 애벌 헹굼·세제 설거지·헹굼을 거쳐 건조대에 엎어 두고, 싱크대를 닦아 마무리하기.
- **시청자가 보게 될 흐름**: 식탁 위 빈 그릇 → 싱크대에 그릇이 가득 → 고무장갑을 끼고 시작 → 컵·그릇·접시·수저·프라이팬 순서로 씻는다 → 헹궈서 건조대에 올린다 → 싱크대를 닦는다 → 텅 빈 싱크대로 끝난다. **가득 찬 싱크대에서 빈 싱크대까지**가 하나의 이야기다.
- **예상 완성 길이**: 약 5–7분. 설거지 자체는 반복 동작이 많아 실제 시간보다 짧게 편집된다.
- **장소·시간·준비물**: 집 부엌. 식사 직후(점심 또는 저녁)라면 실제 그릇이 자연스럽게 생긴다. S011에서 산 재료로 요리해 먹은 뒤라면 앞 회차와 이어지는 이야기가 된다. 고무장갑, 수세미(스펀지), 주방 세제, 행주, 식기 건조대. 그릇은 종류가 다양하게: 컵, 밥그릇, 국그릇, 접시, 숟가락·젓가락, 프라이팬이나 냄비 하나(기름기·눌어붙은 것 있으면 좋음).
- **촬영 방식**: 가로 화면, 혼자 촬영 기준. 싱크대 위·옆에 삼각대(또는 클램프·암)로 고정 화면을 기본으로 하고, 손동작 클로즈업은 휴대폰으로 추가 촬영. 현장에서는 행동과 짧은 자연 발화를 찍고, 설명은 편집 화면을 보며 후시녹음한다.
- **촬영 전 확인**: 싱크대 위 조명 색(형광등·주광 섞임), 물 튀는 범위(카메라·마이크 방수 거리), 창이 있으면 역광 방향, 건조대 위치(싱크대 옆/위), 물소리 크기 — 후시녹음이라 문제없지만 현장 발화를 살리려면 물을 잠시 잠그고 말한다.

## 이번 편의 연결 원칙 — ‘뚝뚝 끊기지 않게’

1. **싱크대가 이야기를 끈다**: 그릇이 쌓인 싱크대 → 반쯤 빈 싱크대 → 텅 빈 싱크대. **같은 위치·같은 구도의 고정 컷**을 처음·중간·끝에 찍는다(삼각대 위치 테이프 표시).
2. **건조대가 반대로 찬다**: 싱크대가 비는 만큼 건조대가 찬다. 건조대도 같은 구도로 빈 상태 → 반쯤 → 가득을 찍어 두면, 두 화면을 번갈아 붙여 진행이 보인다.
3. **그릇 하나가 손에서 손으로**: 씻기(수세미) → 헹구기(물줄기) → 건조대에 올리기까지 **같은 그릇 하나를 끝까지** 따라가는 컷을 그릇 종류마다 하나씩 찍는다. 컷은 동작 도중(그릇을 물줄기 아래로 옮기는 순간)에 바꾼다.
4. **소리가 먼저 넘어간다**: 물 트는 소리, 그릇 부딪히는 소리, 수세미 거품 소리를 다음 컷 앞에 0.5–1초 먼저 깐다. 장면마다 **현장음만 15초** 따로 녹음.
5. **같은 크기로 이어 붙이지 않는다**: 반복 동작이 많아 점프컷이 생기기 쉽다. 위에서 내려다보는 손 컷 ↔ 옆 45도 미디엄 ↔ 물줄기 클로즈업을 번갈아 쓴다.
6. **물로 시간 건너뛰기**: 프라이팬을 물에 담가 두는 장면이 있으면, 담그기 → 다른 그릇 설거지 → 다시 프라이팬으로 돌아오기가 자연스러운 시간 생략이 된다.

화면 정지, 디졸브 남발은 쓰지 않는다. 연결이 어색하면 연결용 컷(흐르는 물줄기, 거품 클로즈업, 건조대에서 물방울 떨어지는 그릇)을 넣는다.

## 반복 설계 — 실제로 많이 쓰는 말을 여러 번

설거지는 **같은 동작(씻고 → 헹구고 → 올리기)이 그릇만 바꿔 계속 반복**되는 일이라, 같은 문장 틀을 자연스럽게 여러 번 말하기 좋다.

### 핵심 문장 (영상 전체에서 3번 이상)

| 핵심 문장·문형 | 다시 나오는 장면 | 바뀌는 부분 |
|---|---|---|
| ＿＿을/를 씻어요. → 헹궈요. → 올려요. | 3 컵 → 4 그릇·접시 → 5 수저 → 6 프라이팬 | 그릇 이름 (컵을 / 접시를 — 을/를 두 형태) |
| 깨끗해요. / 아직 더러워요. | 3·4 그릇 확인 → 6 프라이팬 → 7 싱크대 | 그릇·싱크대, 전후 대비 |
| 그릇이 많아요. → 다 했어요. / 깨끗해요. | 1 시작 → 7 마무리 | 처음과 끝 대비 |
| 하나 더. / 이것도. | 3·4·5 다음 그릇을 집을 때마다 | 집는 그릇 |
| 기름이 많아요. → 뜨거운 물로 씻어요. | 4 접시 → 6 프라이팬 | 접시 → 프라이팬 |
| 조심해요. | 5 칼·유리컵 → 6 뜨거운 물 | 실제로 조심할 물건 |

위 문장은 예시다. 촬영자가 실제로 쓰지 않을 말은 빼고 평소에 하는 말로 바꾼다. A1–A2 범위의 짧은 문장을 중심으로 한다. “물에 담가 두면 잘 떨어져요”처럼 이유를 말하는 문장은 B1 정도이니, 쓴다면 눌어붙은 것이 쉽게 떨어지는 화면과 함께 한 번만 쓴다.

### 반복하는 방법

1. **그릇만 바꿔 반복**: “컵을 씻어요. 헹궈요.” → “접시를 씻어요. 헹궈요.” 같은 리듬을 그릇마다. 그릇 하나당 씻기·헹구기 클로즈업이 필요하다.
2. **을/를이 자연스럽게 섞이게**: 이름에 받침이 있는 그릇(컵·밥그릇·프라이팬·숟가락)과 받침이 없는 그릇(접시·냄비·포크)을 번갈아 씻으면 “컵을 / 접시를”이 저절로 들린다. 문법 포인트 후보.
3. **현장 발화 → 후시로 다시**: 물을 잠그고 실제로 한 말(“아, 뜨거워!”, “어, 깨끗하다”)을 현장음으로 들려준 뒤 다음 화면에서 후시로 천천히(“뜨거워요.” “깨끗해요.”).
4. **전후 대비**: “아직 더러워요” → (한 번 더 문지르고) → “깨끗해요.” / “그릇이 많아요” → “다 했어요.”
5. **마무리 되짚기**: “컵을 씻고, 그릇을 씻고, 프라이팬을 씻었어요. 다 했어요.” — 가득 찬 건조대와 빈 싱크대 화면 위에.

### 반복이 화면 정지가 되지 않도록

- 같은 문장을 다시 말할 때마다 **다른 그릇·다른 화면**을 붙인다. 같은 컷을 늘리지 않는다.
- 반복이 들어가는 장면(3·4·5·6)은 그릇마다 위·옆 두 크기를 넉넉히 찍는다.
- 문장 사이에 물소리만 들리는 1–2초를 둔다. 학습자가 따라 말할 틈이 생긴다.
- “이건 수세미예요” 같은 단순 이름 설명은 줄이고, 처음 집어 들 때 한 번만.

## 영상 소스 계획

샷 길이는 **쓸 수 있는 원본 분량** 기준이다. 각 샷은 동작 시작 3초 전부터 끝난 뒤 3초까지 찍는다.

### 장면 1 · 그릇이 많아요

- **보여 줄 행동·정보**: 밥을 다 먹었다. 식탁의 빈 그릇을 모아 싱크대로 가져간다. 싱크대에 그릇이 쌓인다.
- **필수 샷**: 빈 그릇이 놓인 식탁 와이드(위 45도, 고정 8초); 그릇을 겹쳐 쌓는 손(미디엄 10초); 그릇을 들고 걷기(왼→오, 10초); 그릇이 가득 찬 싱크대(**위치 표시**, 고정 10초).
- **추가 샷**: 남은 음식을 음식물 쓰레기통에 버리는 손(있으면), 식탁을 행주로 한 번 훔치기.
- **반복용**: “그릇이 많아요.” ① — 식탁 와이드 → 싱크대 와이드에 나눠 두 번 들려줄 수 있게. 마지막 빈 싱크대와 **같은 구도**.
- **후시녹음용 연속 화면**: 그릇 모으기 → 걷기 → 싱크대에 내려놓기 25초.
- **촬영 기법**: 싱크대 와이드는 삼각대 고정, 테이프로 표시.
- **소리·빛**: 그릇 부딪히는 소리. 식탁 쪽과 싱크대 쪽 조명 색 차이 확인.
- **연결·대안**: 식탁 장면이 어색하면 싱크대 와이드에서 바로 시작한다.
- **꼭 말하고 싶은 내용**: 밥을 다 먹었다 → 설거지를 한다.
- **촬영 후 직접 붙일 이야기**: 무엇을 먹었는지(S011 재료라면 연결), 설거지 담당이 누구인지.

### 장면 2 · 시작 준비

- **보여 줄 행동·정보**: 고무장갑을 끼고, 물을 틀고 온도를 맞추고, 수세미에 세제를 짜서 거품을 낸다. 기름 묻은 프라이팬은 미리 물에 담가 둔다(실제로 그렇게 할 때만).
- **필수 샷**: 고무장갑 끼기(미디엄·클로즈업 두 크기, 8초); 물 트는 손과 물줄기(클로즈업 6초); 물 온도 확인하는 손(6초); 세제 짜기(클로즈업 8초); 수세미 거품 내기(클로즈업 8초); 프라이팬에 물 받기(있으면 10초).
- **추가 샷**: 세제 통 라벨, 거품이 부풀어 오르는 초근접.
- **반복용**: 물 온도를 보며 “앗, 뜨거워요.” / “따뜻해요.” (실제 반응일 때). 프라이팬 담그기를 하면 장면 6과 짝.
- **후시녹음용 연속 화면**: 장갑 → 물 → 세제 → 거품까지 30초.
- **촬영 기법**: 손 클로즈업은 위에서 내려다보는 각도가 잘 보인다. 물 튀는 거리 확보.
- **소리·빛**: 장갑 ‘탁’ 소리, 물 트는 소리, 세제 짜는 소리 — 각 15초.
- **연결·대안**: 고무장갑을 안 쓰면 맨손 그대로 찍는다(연기하지 않는다).
- **꼭 말하고 싶은 내용**: 장갑 끼고, 물 틀고, 세제.
- **촬영 후 직접 붙일 이야기**: 장갑을 쓰는 이유, 좋아하는 수세미.

### 장면 3 · 컵부터 씻어요

- **보여 줄 행동·정보**: 깨끗한 것(컵)부터 씻는다. 문지르기 → 헹구기 → 확인 → 건조대에 엎어 놓기. 이 리듬을 처음 보여 주는 장면이라 천천히.
- **필수 샷**: 컵 하나를 끝까지 따라가는 컷(씻기 → 헹구기 → 건조대, 끊지 않고 20초); 컵 안쪽을 수세미로 돌려 닦는 손(클로즈업 8초); 물줄기 아래서 거품이 씻겨 내려가는 컷(클로즈업 6초); 빛에 컵을 비춰 보는 손(6초); 건조대에 엎어 놓기(6초).
- **추가 샷**: 컵 2–3개 더(같은 동작, 다른 크기로), 유리컵이 빛나는 클로즈업.
- **반복용**: “컵을 씻어요. 헹궈요. 올려요.” ① / “깨끗해요.” ① / 다음 컵을 집으며 “하나 더.”
- **후시녹음용 연속 화면**: 컵 3개 분량 40초 이상. 위 컷과 옆 컷을 번갈아.
- **촬영 기법**: 고정 와이드(옆 45도)는 계속 돌려 두고, 휴대폰으로 위에서 손 클로즈업 동시 촬영.
- **소리·빛**: 유리 ‘뽀득’ 소리. 유리 반사에 조명·카메라가 비치지 않게.
- **연결·대안**: 컵이 없으면 밥그릇부터.
- **꼭 말하고 싶은 내용**: 씻고 → 헹구고 → 올린다.
- **촬영 후 직접 붙일 이야기**: 씻는 순서가 있는지(컵 먼저, 기름 많은 것 나중 등 실제 습관).

### 장면 4 · 그릇과 접시

- **보여 줄 행동·정보**: 밥그릇·국그릇·접시를 씻는다. 같은 리듬을 그릇만 바꿔 반복. 기름 묻은 접시에서 한 번 더 문지르는 순간이 있으면 살린다.
- **필수 샷**: 그릇마다 씻기 클로즈업(그릇당 6–8초, 3–4개); 밥풀이 붙은 밥그릇 클로즈업(6초); 기름진 접시를 문지르는 손(8초); 손으로 접시를 문질러 ‘뽀득’ 확인(6초); 건조대 같은 구도(반쯤 찬 상태, 고정 8초).
- **추가 샷**: 싱크대 안 그릇이 줄어드는 같은 구도 컷(장면 1 위치에서).
- **반복용**: “밥그릇을 씻어요.” / “접시를 씻어요.” (을/를). “기름이 많아요.” ① → “아직 더러워요.” → 한 번 더 → “깨끗해요.” ②. “하나 더.” / “이것도.”
- **후시녹음용 연속 화면**: 그릇 3–4개 60초 이상.
- **촬영 기법**: 그릇 하나는 위, 다음 그릇은 옆, 그다음은 물줄기 클로즈업처럼 크기를 번갈아 찍어 둔다.
- **소리·빛**: 그릇 부딪히는 소리, 물 흐르는 소리.
- **연결·대안**: 기름진 접시가 없으면 “기름이 많아요”는 장면 6(프라이팬)에서만.
- **꼭 말하고 싶은 내용**: 같은 순서 반복, 깨끗해질 때까지.
- **촬영 후 직접 붙일 이야기**: 가장 귀찮은 그릇.

### 장면 5 · 숟가락, 젓가락 (조심해요)

- **보여 줄 행동·정보**: 수저를 한 줌 쥐고 한꺼번에 문지른다. 칼이나 가위가 있으면 날 방향을 조심하며 따로 씻는다. 수저통에 꽂는다.
- **필수 샷**: 수저 한 줌을 문지르는 손(클로즈업 8초); 젓가락 한 쌍 맞추기(6초); 칼을 조심스럽게 씻는 손(있으면, 클로즈업 8초); 수저통에 꽂기(6초).
- **추가 샷**: 수저가 부딪히는 ‘짤그락’ 소리 컷.
- **반복용**: “숟가락을 씻어요.” / “젓가락을 씻어요.” “조심해요.” ① (칼·유리). 젓가락이 한 짝 없으면 “어? 한 짝 어디 있어요?” — 실제로 있을 때만.
- **후시녹음용 연속 화면**: 25–30초.
- **촬영 기법**: 칼은 날이 카메라·손 쪽을 향하지 않게 각도 주의. 위에서.
- **소리·빛**: 수저 소리 15초.
- **연결·대안**: 칼이 없으면 “조심해요”는 장면 6의 뜨거운 물·무거운 냄비에서.
- **꼭 말하고 싶은 내용**: 수저는 한꺼번에, 칼은 조심.
- **촬영 후 직접 붙일 이야기**: 한국 수저(숟가락+젓가락) 이야기 한 줄.

### 장면 6 · 마지막은 프라이팬

- **보여 줄 행동·정보**: 담가 두었던 프라이팬(또는 냄비)을 꺼낸다. 기름·눌어붙은 것을 뜨거운 물과 수세미로 닦는다. 한 번에 안 지워지면 다시 문지른다.
- **필수 샷**: 담가 둔 프라이팬(위에서, 고정 6초 — 장면 2와 같은 구도면 시간 생략); 물을 버리는 동작(8초); 기름을 문지르는 손(클로즈업 15초, 끊지 않고); 뜨거운 물로 헹구는 컷(김이 보이면 좋음, 8초); 깨끗해진 팬 바닥을 빛에 비추기(6초); 건조대나 가스레인지 위에 올리기(6초).
- **추가 샷**: 거품이 기름과 함께 빠지는 배수구 쪽 클로즈업, 무거운 냄비를 두 손으로 드는 미디엄.
- **반복용**: “프라이팬을 씻어요.” “기름이 많아요.” ② → “뜨거운 물로 씻어요.” “아직 더러워요.” ② → “깨끗해요.” ③. “조심해요.” ② (뜨거운 물).
- **후시녹음용 연속 화면**: 꺼내기 → 문지르기 → 헹구기 → 올리기 40초 이상.
- **촬영 기법**: 김은 역광(창·조명 뒤쪽)에서 잘 보인다. 손이 어두워지지 않게 노출 확인.
- **소리·빛**: 수세미로 팬 문지르는 ‘쓱쓱’ 소리 15초.
- **연결·대안**: 프라이팬이 없으면 냄비·뚝배기로. 눌어붙은 게 없으면 “아직 더러워요”는 빼고 “기름이 많아요”만.
- **꼭 말하고 싶은 내용**: 제일 힘든 것을 마지막에, 깨끗해질 때까지.
- **촬영 후 직접 붙일 이야기**: 실제로 무엇을 요리했던 팬인지.

### 장면 7 · 다 했어요

- **보여 줄 행동·정보**: 물을 잠그고, 싱크대와 배수구를 한 번 헹구고, 행주로 주변 물기를 닦는다. 장갑을 벗어 건다. 가득 찬 건조대와 텅 빈 싱크대를 본다.
- **필수 샷**: 물 잠그는 손(클로즈업 4초); 싱크대 안쪽 헹구기(8초); 행주로 물기 닦기(10초); 장갑 벗어 걸기(8초); 가득 찬 건조대(장면 3·4와 **같은 구도**, 고정 8초); 빈 싱크대(장면 1과 **같은 구도**, 고정 10초).
- **추가 샷**: 건조대 그릇에서 물방울이 떨어지는 클로즈업, 손을 닦고 한숨 돌리는 모습, 부엌 전체 와이드.
- **반복용**: “다 했어요.” “깨끗해요.” ④ — 그리고 오늘 한 일 되짚기: “컵을 씻고, 그릇을 씻고, 프라이팬을 씻었어요. 다 했어요.”
- **후시녹음용 연속 화면**: 물 잠그기 → 닦기 → 장갑 → 건조대 → 빈 싱크대 40초.
- **촬영 기법**: 마지막 두 고정 컷은 앞 장면과 같은 삼각대 위치·줌.
- **소리·빛**: 물이 멈춘 뒤의 조용함, 물방울 소리.
- **연결·대안**: 건조대 대신 식기세척기에 넣는 집이면 장면을 ‘손으로 씻는 것 vs 식기세척기’ 나누기로 바꿔도 된다.
- **꼭 말하고 싶은 내용**: 다 했다, 깨끗하다.
- **촬영 후 직접 붙일 이야기**: 시청자에게 질문 — 설거지를 좋아하는지, 어떤 그릇부터 씻는지.

## 꼭 담을 대사·표현

정확한 원고는 촬영 전에 확정하지 않는다. 아래 문장은 화면과 실제 경험이 맞을 때만 쓰는 짧은 예시다.

| 장면 | 말하고 싶은 핵심 | 필요한 경우에만 정확한 문장 | 반복 | 화면에서 보여 줄 단서 |
|---|---|---|---|---|
| 1 시작 | 그릇이 많다 | “그릇이 많아요.” | 많아요 → (7) 다 했어요 | 가득 찬 싱크대 |
| 2 준비 | 장갑·물·세제 | 실제에 맞게 직접 결정 | 뜨거워요/따뜻해요 | 장갑 → 물줄기 → 거품 |
| 3 컵 | 씻기·헹구기·올리기 | “컵을 씻어요. 헹궈요.” | 씻어요 ①, 깨끗해요 ①, 하나 더 | 컵 하나를 끝까지 |
| 4 그릇·접시 | 같은 순서 반복 | “접시를 씻어요.” “기름이 많아요.” | 을/를, 아직 더러워요 → 깨끗해요 ② | 밥풀·기름 → 뽀득 |
| 5 수저 | 한꺼번에, 조심 | “조심해요.” | 조심해요 ① | 수저 한 줌, 칼 |
| 6 프라이팬 | 마지막, 깨끗해질 때까지 | “뜨거운 물로 씻어요.” | 기름이 많아요 ②, 더러워요 → 깨끗해요 ③ | 담가 둔 팬 → 김 → 빛나는 바닥 |
| 7 마무리 | 다 했다 | “다 했어요.” | 깨끗해요 ④, 되짚기 | 가득 찬 건조대 ↔ 빈 싱크대 |

**문법 포인트 후보**: `＿＿을/를 씻어요` — 그릇 이름만 바꿔 계속 반복되고, 받침에 따라 을/를이 바뀌는 것이 자연스럽게 들린다 (컵을 / 접시를). 최종 대본을 보고 확정한다.

## 촬영 체크리스트

- [ ] 그릇 종류를 다양하게: 컵·밥그릇·접시·수저·프라이팬 (받침 있는 이름과 없는 이름 섞기)
- [ ] **같은 구도 여러 번**: 싱크대 가득 → 반 → 빔 / 건조대 빔 → 반 → 가득 — 삼각대 위치 테이프 표시
- [ ] 그릇 종류마다 ‘하나를 끝까지 따라가는 컷’ (씻기 → 헹구기 → 올리기)
- [ ] 동작 도중 컷을 위한 두 크기: 장갑 끼기, 그릇 옮기기, 문지르기
- [ ] 현장음 15초씩: 물 트는 소리, 거품, 그릇 부딪힘, 수저, 팬 문지르기, 물 멈춘 뒤 조용함
- [ ] 카메라·마이크 물 튀는 거리 확인, 유리·스테인리스 반사 확인
- [ ] 현장 발화는 물을 잠깐 잠그고
- [ ] 연결 컷: 흐르는 물줄기, 거품 클로즈업, 물방울 떨어지는 건조대, 그릇 들고 걷기

## 촬영 후

먼저 장면 연결표대로 이어 붙여 말 없이도 흐름이 보이는 5–7분 편집본을 만든다. 그 화면을 보며 촬영자가 직접 최종 대본을 쓴다. 무엇을 먹었는지, 씻는 순서, 장갑을 쓰는지 같은 내용은 실제 사실만 말한다. 후시녹음이 화면보다 길면 화면을 멈추기 전에 말을 줄이거나 관련 행동 화면으로 이어 간다. 완성 대본을 받은 뒤 전체 난이도를 범위로 검토하고 필요한 에셋만 따로 살핀다.
