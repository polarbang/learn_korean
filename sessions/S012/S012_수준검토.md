# S012 · 최종 대본 수준 검토

- **검토한 대본**: S012_captions/S012_captions.kr.sbv (최종 한국어 자막 107줄, ‘후라이팬 → 프라이팬’ 수정본). 별도 S012_대본.md는 없어 자막을 최종 대본으로 봤다. 음성은 확인하지 않아 말하기 속도는 판단하지 않는다.
- **전체 난이도 범위**: **A1–B1** (중심은 A2)

## 판단 근거

- **문장 길이·형태**: 대부분 2–4어절의 짧은 해요체 현재 문장이고, 같은 틀이 물건만 바꿔 반복된다. “컵을 물로 헹궈요 / 그릇을 씻어요 / 숟가락을 씻어요 / 젓가락을 씻어요 / 컵을 건조대에 올려요”. 명사만 보여 주는 줄(프라이팬, 밥솥, 그릇, 컵…)도 많다 → A1.
- **A1 문법**: -아요/어요, 을/를, 에(장소), (으)로(도구: 수세미로, 물로), 안 + 동사(세제를 안 써요), -았어요(먹었어요, 말랐어요), -ㄹ 거예요(할 거예요).
- **A2 문법**: -고 연결(물을 틀고, 그릇을 헹구고, 물을 털고), -아서/어서 순서(비벼서 거품을 내요, 뒤집어서 올려요), -기 전에(설거지를 하기 전에), -(으)ㄹ 때(칼을 씻을 때는), -(으)면(물을 묻히면 거품이 더 잘 나요), -(으)ㄹ 수 있어요(분리할 수 있어요), -고 나면 / -고 나서(밥을 먹고 나면, 밥 먹고 나서), 더 + 형용사·부사(더 깨끗하게, 더 잘).
- **B1에 가까운 부분**: 아래 ‘B1 표현’ 참고. 수가 적고 대부분 바로 앞뒤에 쉬운 문장으로 다시 말하거나 화면으로 보여 줘서, 영상 전체 범위를 B1까지만 넓힌다.

### B1 표현 (B2 이상은 아님)

| 대사 | 이유 |
|---|---|
| 물을 담아놔야 / 나중에 씻기가 편해요 | -아야(조건·필요), -아 놓다, -기가 편하다(명사형) 세 가지가 한 문장에 겹친다. 이번 영상에서 가장 어려운 문장. |
| 밥솥은 물로만 헹궈도 충분해요 | -만 + -아도 충분하다. 바로 뒤 “세제를 안 써요”가 뜻을 풀어 준다. |
| 헹군 그릇은 / 후라이팬에 담아놓은 물 / 어제 저녁에 한 설거지 | 과거 관형형(-ㄴ/-은) + -아 놓은. 초급 후반~B1. |
| 설거짓거리, 찬장, 간이 건조대, 분리하다, 날카롭다, 묻히다, 비비다 | 어휘 수준은 B1 전후. 다만 모두 화면에 물건·동작이 직접 보인다. ‘찬장’과 ‘간이’는 일상에서 덜 쓰여 학습자에게 가장 낯설 수 있다. |

- **B2 이상으로 느껴지는 부분**: 없음.

## 간단히 바꿀 수 있는 표현 (선택 사항, 이미 업로드했으므로 다음 회차 참고용)

| 원문 | 제안 | 이유 |
|---|---|---|
| 물을 담아놔야 나중에 씻기가 편해요 | 물을 담아 놓으면 나중에 쉽게 씻을 수 있어요 | -아야·-기가 편하다 대신 이미 영상에 나온 -(으)면, -(으)ㄹ 수 있어요로 바꿔 A2에 맞춘다. |
| 밥솥은 물로만 헹궈도 충분해요 | 밥솥은 물로만 헹궈요 | -아도 충분하다를 빼도 뒤 문장(세제를 안 써요)과 함께 뜻이 전해진다. |
| 간이 건조대 | 작은 건조대 | ‘간이’는 한자어라 낯설다. 화면에 접는 작은 건조대가 보이므로 ‘작은’으로 충분하다. |
| 찬장 | (그대로 두거나) 그릇장 | ‘찬장’은 덜 쓰이는 말. 그대로 써도 화면으로 이해된다. |

## 영상 맥락이 뜻을 돕는 부분

- 설거짓거리를 하나씩 보여 주며 이름을 부르는 장면(프라이팬~가위)이 뒤에 나올 명사를 미리 알려 준다.
- 씻어요 / 헹궈요 / 올려요가 같은 동작과 함께 여러 번 반복돼 동사 뜻이 화면으로 고정된다.
- 수세미·세제·거품, 뒤집어서 올리기, 가위 분리, 간이 건조대 펼치기는 손동작이 바로 보인다.
- “날카로운 부분을 조심해요”는 칼날을 보여 주는 화면과 함께라면 B1 어휘라도 이해 부담이 작다.

## 이해에 추가 화면·사진·아이콘이 필요한 부분

- 영상 확인 필요. 대본만으로 보면 “물을 담아놔야 나중에 씻기가 편해요”(원리 설명)와 “밥솥은 물로만 헹궈도 충분해요”(세제를 안 쓰는 이유)가 화면만으로 전달되기 가장 어려운 문장이다.
