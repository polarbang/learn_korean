## 인트로에서 전할 내용

- **핵심**: 한국에는 아파트에 사는 사람이 많다. 오늘은 내가 사는 아파트 단지를 보여 주겠다.
- **짧은 말의 예시**: “한국에는 아파트가 많아요. 오늘은 제가 사는 아파트 단지를 보여드릴게요.” 촬영 후 실제 첫 화면과 말하는 속도에 맞춰 직접 고친다.
- **사실 확인**: 2024년 인구주택총조사에서 아파트에 거주하는 **일반가구**는 53.9%였다. 가구 비율을 사람 비율로 바꿔 말하거나 “한국 사람들은 대부분 아파트에 산다”라고 강조하기보다, 영상에서는 “아파트에 사는 사람이 많아요”처럼 자연스럽게 말한다. [통계청 2024년 인구주택총조사](https://sri.kostat.go.kr/boardDownload.es?bid=510205&list_no=443718&seq=1)

### 장면 연결의 핵심

1. **집 안 → 밖**: 옷을 입고 신발을 신는 행동에서 엘리베이터, 건물 외관으로 이어 간다. 밖으로 순간 이동한 느낌이 들지 않게 문·버튼·걸음 중 한 컷을 남긴다.
2. **시설 → 시설**: 간판을 연달아 나열하기보다 길을 걷는 화면을 사이에 둔다. 각 장소에서는 ‘무엇이 있는지’와 ‘여기서 무엇을 하는지’가 보이는 컷을 고른다.
3. **예상 밖 장면**: 고양이를 실제로 발견했다면 놀이터·산책길에서 고양이를 본 순서대로 쓴다. 단지 소개에서 가장 기억에 남을 수 있는 자연스러운 순간이다.
4. **오후 → 저녁**: 하늘·가로등·건물 조명이 바뀌는 화면으로 시간이 흐른 것을 보여 준다. 낮과 밤의 컷을 무작위로 섞지 않는다.
5. **귀가**: 주차장이나 건물 입구가 마지막 목적지가 되는 게 아니라, 엘리베이터와 현관을 통해 다시 집으로 돌아온다는 느낌으로 닫는다.

## 구간별 후시녹음과 영상 소스

대사를 먼저 길게 써서 화면에 끼워 넣지 않는다. 실제 행동과 전환을 먼저 이어 본 뒤, 그 위에서 꼭 필요한 사실과 반응만 말한다. 아래는 문장별 대본이 아니라 **말할 내용의 범위**다.

| 구간 | 꼭 말할 내용 | 후시녹음 중 계속 움직일 화면 |
|---|---|---|
| 인트로 | 한국에는 아파트가 많고, 오늘 내 단지를 소개한다 | 창밖 건물 → 외투 입기 → 신발·현관 |
| 건물과 길 | 내가 사는 건물에서 내려와 단지를 걷기 시작한다 | 엘리베이터 문 → 건물 전체 → 걸음 → 나무 |
| 쉬는 곳 | 정자·산책길 등 실제로 보이는 공간과 내가 여기서 하는 일 | 길을 따라 걷기 → 정자에 가까워지기 → 주변을 둘러보기 |
| 생활공간 | 주민들이 쓰는 택배함·재활용 공간 등, 내가 실제로 사용하는 방법 | 입구 → 물건·표지 → 손이나 이동 → 다음 길 |
| 가게 | 보이는 가게가 무엇이고 평소 들르는지 여부 | 가게로 접근 → 외관 → 지나가는 길. 구매하지 않았다면 구매했다고 말하지 않기 |
| 놀이터·고양이 | 놀이터를 보다가 고양이를 만났다면 그때의 실제 반응 | 놀이터 전체 → 고양이 발견 → 움직임·표정 → 다시 걷기 |
| 귀가 | 해가 저물어 집으로 돌아간다 | 저녁 하늘·가로등 → 주차장·입구 → 엘리베이터 |

긴 설명이 필요한 순간에는 같은 화면을 정지하기보다 가까이 가는 컷, 손이나 발의 행동, 주변에서 움직이는 것, 다음 장소로 걷는 컷을 연결한다. 시설 이름만 반복하며 목록을 읽는 방식은 피한다. 후시녹음 없는 짧은 구간에는 발소리·바람·놀이터나 주차장 분위기 등 실제 현장음을 살린다.

## 실제 클립 검토 때 결정할 것

- [ ] 0003·0004의 인사가 실제 인트로로 쓸 만한지 확인한다. 말이나 구도가 맞지 않으면 창밖·출발 화면 위에 짧은 후시녹음을 얹는다.
- [ ] 우편함·택배함, 재활용 공간 등은 대표 프레임의 추정이므로 전체 클립을 보고 정확한 시설 이름을 쓴다.
- [ ] 빵집·편의점·횡단보도·하천 화면은 단지 안과 밖의 경계를 정확하게 표현한다. 단지 밖이라면 ‘집 근처’로 말하거나 흐름을 흐리면 제외한다.
- [ ] 고양이 장면은 발견부터 떠날 때까지 실제 순서를 확인하고, 너무 길면 가장 다른 행동이 보이는 컷만 남긴다.
- [ ] 아파트 이름·동호수·집 위치를 알려 주는 표지, 다른 주민의 얼굴·차량번호가 의도치 않게 크게 보이는지 확인한다.
- [ ] 컷의 소리와 움직임을 확인해 7~8분이 자연스럽게 나오는지 판단한다. 반복 장면을 늘리거나 화면을 정지해 목표 시간을 맞추지 않는다.
