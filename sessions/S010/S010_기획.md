# S010 · 집에서 빨래하기 — 촬영 기획

- **주제**: 쌓인 빨래를 세탁기로 빨고, 건조기에 넣을 것과 건조대에 널 것을 나눠 말린 뒤, 다 마른 빨래를 개서 정리하기.
- **시청자가 보게 될 흐름**: 빨래 바구니가 가득 차 있다 → 세탁기를 돌린다 → 다 된 빨래를 꺼내 “이건 건조기, 이건 건조대”로 나눈다 → 각각 말린다 → 마른 빨래를 걷고 갠다 → 빈 바구니로 끝난다. 가득 찬 바구니에서 빈 바구니까지가 하나의 이야기다.
- **예상 완성 길이**: 약 6–8분. 기다리는 시간은 화면 변화(세탁기 창, 남은 시간 표시, 창밖 빛)로 압축한다.
- **장소·시간·준비물**: 집(세탁실·베란다·거실). 맑은 날 오전에 시작하면 건조대 빨래가 마르는 과정과 빛의 변화를 같은 날 담기 좋다. 빨래는 화면에 보여도 괜찮은 것만 고른다(수건, 티셔츠, 청바지, 양말, 니트 등). 속옷처럼 사적인 옷은 따로 빨거나 화면 밖에서 처리한다. 카메라·삼각대·여분 배터리, 세제·섬유유연제, 건조대·옷걸이·빨래집게.
- **촬영 방식**: 가로 화면, 혼자 촬영 기준. 삼각대로 고정 화면을 기본으로 하고, 손동작 클로즈업은 핸드헬드로 찍는다. 현장에서는 행동과 짧은 자연 발화를 찍고, 설명은 편집한 화면을 보며 후시녹음한다.
- **촬영 전 확인**: 세탁기 종류(드럼/통돌이)와 세탁·건조 소요 시간, 끝날 때 나는 알림음, 건조대를 놓을 자리와 그 자리의 빛, 빨래를 갤 자리(소파·바닥·침대). 건조기에 넣으면 안 되는 옷이 실제로 있는지 라벨로 확인한다(이 편의 ‘나누기’ 장면이 여기서 나온다).

## 이번 편의 연결 원칙 — ‘뚝뚝 끊기지 않게’

장면이 바뀔 때마다 **무언가가 화면을 넘어 이어지게** 한다. 장면마다 아래 중 최소 하나를 촬영 단계에서 확보한다.

1. **빨래 바구니가 이야기를 끈다**: 가득 찬 바구니 → 젖은 빨래가 담긴 바구니 → 마른 빨래가 담긴 바구니 → 빈 바구니. 바구니가 장면마다 같은 물건으로 보이게 하고, 바구니를 들고 이동하는 화면을 꼭 찍는다.
2. **동작에서 자른다 (cut on action)**: 세탁기 문을 닫는 순간, 옷을 터는 순간, 수건을 반으로 접는 순간처럼 **움직임 도중에** 컷을 바꾼다. 같은 동작을 두 크기(미디엄/클로즈업)로 찍어 둔다.
3. **소리가 먼저 넘어간다 (J컷·L컷)**: 세탁 끝 알림음, 건조기 알림음, 옷 터는 ‘탁탁’ 소리를 앞 장면 끝에 0.5–1초 먼저 깔거나 다음 화면 위로 남긴다. 장면마다 **현장음만 15초씩** 따로 녹음한다.
4. **시간은 화면으로 건너뛴다**: 세탁기 남은 시간 표시(예: 0:52 → 0:01), 창으로 들어오는 빛의 변화, 같은 구도에서 젖은 빨래 → 마른 빨래로 바뀌는 컷. 같은 위치·같은 구도로 두 번 찍어야 하므로 **삼각대 위치를 표시**해 둔다(바닥에 마스킹테이프).
5. **방향을 지킨다**: 세탁실 → 건조대/거실로 갈 때는 화면 **왼쪽에서 오른쪽**으로 걷게 찍는다. 이동 방향이 뒤섞이면 다른 날 찍은 것처럼 보인다.
6. **같은 크기로 이어 붙이지 않는다**: 이어 붙일 두 컷은 크기(와이드↔클로즈업)나 각도(30° 이상)를 다르게 한다. 특히 빨래 개기처럼 반복 동작이 많은 장면에서 점프컷이 생기기 쉽다.
7. **문으로 넘긴다**: 세탁기·건조기 문이 닫히며 화면을 가리는 순간, 베란다 문을 여는 순간을 다음 컷의 시작점으로 쓴다.

화면 정지, 디졸브 남발, 효과음으로 억지로 잇는 방법은 쓰지 않는다. 연결이 어색하면 먼저 ‘연결용 컷’(바구니 들고 걷기, 돌아가는 세탁기 창, 창밖 빛)을 넣는다.

## 반복 설계 — 실제로 많이 쓰는 말을 여러 번

화면을 하나하나 설명하는 대신, **빨래할 때 실제로 하는 말**을 골라 영상 곳곳에서 되풀이한다. 빨래는 같은 동작(넣기·널기·개기)이 물건만 바꿔 계속 반복되는 일이라, 같은 문장을 자연스럽게 여러 번 말하기 좋다.

### 핵심 문장 (영상 전체에서 3번 이상)

| 핵심 문장·문형 | 다시 나오는 장면 | 바뀌는 부분 |
|---|---|---|
| 이건 건조기에 넣어요. / 이건 건조대에 널어요. | 4 나누기 (옷마다) → 5 건조기 → 6 건조대 | 옷 이름, 넣다 ↔ 널다 |
| 빨래가 많아요. → 다 끝났어요. | 1 시작 → 8 마무리 | 처음과 끝 대비 |
| 다 됐어요. | 3 세탁 끝 → 7 건조기 끝 → 7 건조대 | 세탁기·건조기·건조대 |
| 아직 안 말랐어요. → 다 말랐어요. | 6 널고 나서 → 7 만져 보기 | 전후 대비 |
| 이렇게 개요. / 반으로 접어요. | 8 개기 (수건 → 티셔츠 → 바지) | 옷 이름 |
| ＿＿ 어디 있어요? | 2 세제 → 8 양말 한 짝 | 찾는 물건 |
| 냄새 좋아요. / 따뜻해요. / 축축해요. | 4 꺼낼 때 → 7 건조기에서 꺼낼 때 → 7 건조대 | 실제 느낌 |

위 문장은 예시다. 촬영자가 실제로 쓰지 않을 말은 빼고 평소에 하는 말로 바꾼다. A1–A2 범위의 짧은 문장을 중심으로 한다. “건조기에 넣으면 줄어들어요”처럼 이유를 말하는 문장은 B1 정도이니, 쓴다면 줄어든 옷을 손으로 보여 주는 화면과 함께 한 번만 쓴다.

### 반복하는 방법

1. **물건만 바꿔 반복**: 나누기 장면에서 옷 한 벌마다 같은 문장 틀을 쓴다 (“수건은 건조기. 티셔츠도 건조기. 니트는… 건조대.”). 옷 하나당 들어 올리는 손 클로즈업 하나가 필요하다.
2. **장면 사이 반복**: 같은 문형이 다른 장면에서 다시 나온다 (“다 됐어요” — 세탁기 → 건조기 → 건조대).
3. **현장 발화 → 후시로 다시**: 옷을 만지며 실제로 한 말(“아, 따뜻해”)을 현장음으로 들려준 뒤, 다음 화면에서 후시로 한 번 더 천천히 말한다 (“따뜻해요.”).
4. **전후 대비**: 같은 상태를 처음과 나중에 말한다. “아직 안 말랐어요” → “다 말랐어요”, “빨래가 많아요” → “다 끝났어요”. 상태 변화가 이야기의 진행이 된다.
5. **마무리 되짚기**: 마지막에 오늘 한 일을 핵심 문장으로 짧게 묶는다 (“빨래하고, 건조기에 넣고, 건조대에 널고, 갰어요. 다 끝났어요.”). 빈 바구니와 정리된 서랍 화면 위에 흐르게 한다.

### 반복이 화면 정지가 되지 않도록

- 같은 문장을 다시 말할 때마다 **다른 화면**을 붙인다 (옷을 들어 올리는 손 → 건조기에 넣는 손 → 건조대에 거는 손). 같은 컷을 늘리거나 멈추지 않는다.
- 그래서 반복이 들어가는 장면(장면 4·6·8)은 옷마다 클로즈업과 연속 화면을 넉넉히 찍는다.
- 문장 사이에는 현장음만 들리는 1–2초를 둔다. 학습자가 따라 말할 틈이 생긴다.
- 반복 없는 단순 설명(“이건 세탁기예요”)은 줄인다.

## 영상 소스 계획

샷 길이는 **쓸 수 있는 원본 분량** 기준이다. 각 샷은 동작 시작 3초 전부터 끝난 뒤 3초까지 찍는다. 후시녹음이 흐를 동안 화면이 계속 움직이도록, 장면마다 말 없이 쓸 수 있는 연속 화면을 넉넉히 확보한다.

### 장면 1 · 빨래가 많아요

- **보여 줄 행동·정보**: 빨래 바구니가 가득 차 있다. 오늘 빨래를 하기로 한다. 방이나 욕실에서 옷을 몇 벌 더 모아 바구니에 넣어도 좋다.
- **필수 샷**: 가득 찬 바구니 와이드(바닥 높이에서 약간 위, 고정 8–10초); 바구니에 옷을 던져 넣거나 의자에 걸린 옷을 집는 손(미디엄 10초); 바구니 속 클로즈업(위에서, 6–8초); 바구니를 들어 올리는 동작(옆에서, 8초).
- **추가 샷**: 바구니 위로 넘치는 옷, 들어 올릴 때 무거워하는 표정이나 몸짓, 창밖 아침 빛.
- **반복용**: “빨래가 많아요.”를 바구니 와이드 → 넘치는 옷 클로즈업에 나눠 두 번 들려줄 수 있게 찍는다. 마지막 장면의 빈 바구니와 **같은 구도**로 찍는다.
- **후시녹음용 연속 화면**: 옷 모으기 → 바구니 보기 → 들고 걸어가기까지 25–30초.
- **촬영 기법**: 바구니 와이드는 삼각대 고정, 위치를 테이프로 표시. 바구니 들고 걷기는 왼→오.
- **소리·빛**: 옷이 바구니에 떨어지는 소리. 아침 자연광.
- **연결·대안**: 옷 모으기가 어색하면 가득 찬 바구니 와이드에서 바로 들어 올리기로 시작한다.
- **꼭 말하고 싶은 내용**: 빨래가 많아서 오늘 빨래한다.
- **촬영 후 직접 붙일 이야기**: 며칠 동안 빨래를 안 했는지 등 실제 이야기.

### 장면 2 · 세탁기에 넣고 돌리기

- **보여 줄 행동·정보**: 빨래를 세탁기에 넣고, 세제를 넣고, 버튼을 눌러 돌린다. 주머니를 확인하는 동작이 있으면 자연스럽게 넣는다.
- **필수 샷**: 세탁기 앞 와이드(고정 8초); 옷을 한 움큼씩 넣는 손(세탁기 안쪽에서 보이는 각도나 옆 45도, 15–20초); 주머니를 뒤집어 확인하는 손(클로즈업 8초, 있으면); 세제를 계량해 붓는 손(클로즈업 10초); 문 닫기(미디엄·클로즈업 두 크기); 버튼·다이얼 누르기(클로즈업 6–8초).
- **추가 샷**: 세제 통 찾기, 섬유유연제 붓기, 세탁기 화면에 시간이 뜨는 순간.
- **반복용**: 세제를 찾는 짧은 순간이 실제로 있으면 “세제 어디 있어요? … 여기 있어요.” (장면 8의 양말 찾기와 짝).
- **후시녹음용 연속 화면**: 넣기 → 세제 → 문 닫기 → 버튼 → 물 들어가는 소리까지 35–40초.
- **촬영 기법**: 손 클로즈업은 핸드헬드로 천천히. 세탁기 표시창 반사에 카메라가 비치지 않게 각도 조정.
- **소리·빛**: 세제 붓는 소리, 문 닫히는 소리, 버튼음, 물 들어가는 소리 — 각 15초 현장음.
- **연결·대안**: 세탁실이 좁으면 위에서 내려다보는 손 시점으로만 찍는다.
- **꼭 말하고 싶은 내용**: 세탁기에 넣고, 세제를 넣고, 돌린다.
- **촬영 후 직접 붙일 이야기**: 어떤 코스로 돌렸는지, 걸리는 시간.

### 장면 3 · 기다리다가 다 됐어요

- **보여 줄 행동·정보**: 세탁기가 돌아가는 동안 기다린다. 끝나는 알림음이 울리면 문을 열고 젖은 빨래를 바구니에 꺼낸다.
- **필수 샷**: 돌아가는 세탁기 창(정면, 고정 15–20초); 남은 시간 표시를 같은 구도로 여러 번(예: 시작 직후·중간·끝 1분 전, 각 6–8초); 기다리는 동안 짧은 일상 한 컷(차 마시기·창밖 보기 등, 10초 — 실제로 한 일만); 알림음 울릴 때 세탁기 쪽으로 걸어오는 모습(10초); 문 열기 → 젖은 빨래 꺼내 바구니에 담기(미디엄·클로즈업, 20초).
- **추가 샷**: 세탁기 창의 거품, 꺼낸 빨래의 무게감, 축축한 옷을 손으로 쥐는 클로즈업.
- **반복용**: “다 됐어요.” ①. 꺼낼 때 냄새를 맡아 보는 동작이 있으면 “냄새 좋아요.” ①.
- **후시녹음용 연속 화면**: 돌아가는 창 → 시간 표시 → 일상 컷 → 알림음 → 꺼내기까지 40초 이상. 기다리는 시간은 이 컷들로만 건너뛴다.
- **촬영 기법**: 시간 표시 컷은 삼각대 위치를 고정해 매번 같은 구도. 그래야 숫자만 바뀌며 자연스럽게 이어진다.
- **소리·빛**: 세탁기 돌아가는 소리, 탈수 소리, 알림음 15초.
- **연결·대안**: 시간 표시가 없는 세탁기면 창 회전 → 탈수 진동 → 멈춘 창으로 시간을 보여 준다.
- **꼭 말하고 싶은 내용**: 기다린다 → 다 됐다.
- **촬영 후 직접 붙일 이야기**: 기다리는 동안 한 일.

### 장면 4 · 건조기? 건조대? 나누기

- **보여 줄 행동·정보**: 이 편의 중심 장면. 젖은 빨래를 하나씩 들어 올려 건조기에 넣을 것과 건조대에 널 것으로 나눈다. 라벨을 확인하는 동작으로 이유를 보여 준다(니트·얇은 옷은 건조대 등, 실제 기준대로).
- **필수 샷**: 바구니 위에서 본 젖은 빨래(고정 8초); 옷을 하나씩 들어 올리는 손(옷마다 클로즈업 6–8초, 4–6벌); 라벨을 확인하는 손(클로즈업 8초); 두 무더기(또는 두 바구니)로 나뉘는 과정 와이드(고정, 끊지 않고 30–40초); 나뉜 결과(위에서, 8초).
- **추가 샷**: 옷을 탁탁 털어 펴는 동작, 고민하며 옷을 들고 있는 미디엄, 두 무더기를 번갈아 보는 시선.
- **반복용**: 옷마다 “이건 건조기에 넣어요.” / “이건 건조대에 널어요.”를 붙인다. 건조기 쪽 옷과 건조대 쪽 옷을 번갈아 나오게 하면 두 문장을 비교하며 들을 수 있다. 옷 하나당 클로즈업 하나를 꼭 확보한다.
- **후시녹음용 연속 화면**: 첫 옷을 들기부터 마지막 옷까지 끊지 않은 와이드 + 옷별 클로즈업. 편집에서 와이드와 클로즈업을 번갈아 붙여 점프컷을 피한다.
- **촬영 기법**: 삼각대로 와이드 고정, 클로즈업은 같은 과정을 한 번 더 찍지 말고 와이드를 찍는 동안 다른 카메라(휴대폰)로 동시에 찍거나, 옷 몇 벌만 따로 클로즈업.
- **소리·빛**: 젖은 옷을 터는 소리. 두 무더기가 화면에서 구분되게 밝은 바닥이나 두 개의 다른 색 바구니 사용.
- **연결·대안**: 건조기에 못 넣는 옷이 없다면 ‘큰 것은 건조기, 금방 마르는 것은 건조대’처럼 실제 기준으로 나눈다. 기준은 촬영자가 실제로 쓰는 것으로.
- **꼭 말하고 싶은 내용**: 이건 건조기, 이건 건조대 — 그리고 짧은 이유 하나.
- **촬영 후 직접 붙일 이야기**: 집에서 나누는 실제 기준, 건조기에 넣었다가 옷이 줄어든 경험이 있다면.

### 장면 5 · 건조기 돌리기

- **보여 줄 행동·정보**: 건조기 쪽 빨래를 건조기에 넣고 돌린다. 장면 2(세탁기)와 같은 순서라 짧게 간다.
- **필수 샷**: 건조기에 넣는 손(15초); 건조기 시트를 넣거나 필터를 확인하는 손(있으면 8초); 문 닫기 두 각도; 버튼 누르기(6–8초); 돌아가기 시작한 건조기(고정 10초).
- **추가 샷**: 건조기 표시창의 남은 시간.
- **반복용**: 넣으면서 “이건 건조기에 넣어요.”를 한두 번 더. 장면 2의 버튼 누르기와 같은 구도로 찍어 두 장면이 짝을 이루게 한다.
- **후시녹음용 연속 화면**: 넣기 → 닫기 → 버튼 → 회전 시작까지 20–25초.
- **촬영 기법**: 세탁기와 건조기가 붙어 있으면 장면 2와 다른 각도로 찍어 구분한다.
- **소리·빛**: 건조기 돌아가는 소리 15초.
- **연결·대안**: 건조기가 없다면 이 편의 구성을 ‘건조대 + 실내/베란다’로 바꾼다.
- **꼭 말하고 싶은 내용**: 건조기를 돌린다.
- **촬영 후 직접 붙일 이야기**: 건조기 코스·시간.

### 장면 6 · 건조대에 널기

- **보여 줄 행동·정보**: 남은 빨래 바구니를 들고 베란다나 거실로 가서 건조대를 펼치고, 하나씩 털어서 넌다. 옷걸이·빨래집게도 쓴다.
- **필수 샷**: 바구니를 들고 걷기(왼→오, 10–15초); 건조대를 펼치는 동작(와이드 15초); 옷을 탁탁 털기(클로즈업 6–8초, 두세 번); 건조대에 거는 손(옷마다 8–10초, 3–5벌); 옷걸이에 걸기·빨래집게로 양말 집기(클로즈업 각 8초); 다 널린 건조대 와이드(**삼각대 위치 표시**, 고정 10–15초).
- **추가 샷**: 창으로 들어오는 햇빛, 바람에 흔들리는 옷, 젖은 옷에서 물방울이 떨어지는 클로즈업(있으면).
- **반복용**: 옷마다 “이건 건조대에 널어요.” 다 널고 나서 옷을 만져 보며 “아직 축축해요. 아직 안 말랐어요.” ① — 장면 7의 “다 말랐어요”와 짝.
- **후시녹음용 연속 화면**: 걷기 → 펼치기 → 털기 → 널기 → 와이드까지 45–60초.
- **촬영 기법**: 마지막 와이드는 장면 7에서 같은 구도로 다시 찍을 것이므로 삼각대 위치·높이·줌을 기록한다.
- **소리·빛**: 털 때 ‘탁탁’ 소리를 살린다. 역광이면 옷 실루엣이 예쁘지만 손동작이 어두워지지 않게 노출 확인.
- **연결·대안**: 건조대 자리가 좁으면 클로즈업 위주로 찍고 와이드는 한 컷만.
- **꼭 말하고 싶은 내용**: 털어서 넌다, 아직 젖어 있다.
- **촬영 후 직접 붙일 이야기**: 날씨, 마르는 데 얼마나 걸릴지.

### 장면 7 · 다 됐어요, 다 말랐어요

- **보여 줄 행동·정보**: 건조기 알림음이 울려 따뜻한 빨래를 꺼낸다. 몇 시간 뒤 건조대 빨래를 만져 보고 다 말랐는지 확인해 걷는다. 두 곳의 마른 빨래가 한 바구니에 모인다.
- **필수 샷**: 건조기 알림음 → 문 열기 → 꺼내는 손(20초); 따뜻한 빨래를 얼굴이나 손에 대 보는 반응(미디엄 10초); 장면 6과 **같은 구도**의 건조대 와이드, 빛이 달라진 상태(고정 10초); 옷을 만져 보는 손(클로즈업 8초); 걷어서 바구니에 담기(20초).
- **추가 샷**: 건조기 필터의 먼지, 옷걸이에서 옷을 빼는 손, 빨래집게 풀기.
- **반복용**: “다 됐어요.” ②(건조기) → “다 말랐어요.” / “다 됐어요.” ③(건조대). “따뜻해요.”, “냄새 좋아요.” ②. 덜 마른 옷이 하나라도 있으면 “이건 아직 안 말랐어요.” ② — 실제로 있을 때만.
- **후시녹음용 연속 화면**: 건조기 꺼내기 → 건조대로 이동 → 같은 구도 와이드 → 만져 보기 → 걷기까지 50초 이상.
- **촬영 기법**: 장면 6 와이드와 같은 삼각대 위치·줌. 편집에서 젖은 건조대 → 마른 건조대를 바로 붙이면 시간 생략이 한 컷으로 된다.
- **소리·빛**: 알림음, 마른 옷의 바스락 소리. 오후 빛으로 시간 경과를 보여 준다.
- **연결·대안**: 건조대 빨래가 다음 날 마른다면 다음 날 같은 시간대에 찍고, 대사로 “하루 지났어요” 정도만 붙인다.
- **꼭 말하고 싶은 내용**: 다 마르고 다 됐다.
- **촬영 후 직접 붙일 이야기**: 실제로 걸린 시간, 건조기와 건조대 빨래의 느낌 차이.

### 장면 8 · 빨래 개기와 정리

- **보여 줄 행동·정보**: 마른 빨래를 소파나 바닥에 쏟아 놓고 종류별로 갠다. 양말 짝을 맞추다가 한 짝이 없어 찾는 순간이 있으면 살린다. 다 갠 옷을 서랍·옷장에 넣고, 빈 바구니로 끝난다.
- **필수 샷**: 빨래를 쏟는 동작(두 크기); 빨래 더미 와이드(고정, 위나 45도); 수건 개기(클로즈업, 접는 단계가 다 보이게 15초); 티셔츠 개기(15초); 바지 개기(10–15초); 양말 짝 맞추기(클로즈업 15초); 개어 쌓인 옷(8초); 서랍·옷장에 넣는 손(15초); 빈 바구니(장면 1과 **같은 구도**, 고정 10초).
- **추가 샷**: 다 갠 옷 위를 손으로 쓸어 정리하는 동작, 쌓인 수건 높이, 소파에 앉아 쉬는 마지막 모습.
- **반복용**: 옷마다 “이렇게 개요.” / “반으로 접어요.” — 수건 → 티셔츠 → 바지. 양말: “하나, 둘… 어? 양말 한 짝 어디 있어요?” → 찾았을 때 “여기 있어요!” 마지막에 “다 끝났어요.”와 오늘 한 일 되짚기.
- **후시녹음용 연속 화면**: 쏟기 → 종류별 개기 → 쌓기 → 정리 → 빈 바구니까지 60초 이상. 개는 동작은 한 벌을 끝까지 찍고, 편집에서 크기가 다른 컷을 번갈아 붙인다.
- **촬영 기법**: 개는 손은 위에서 내려다보는 고정 화면이 가장 잘 보인다. 와이드는 옆 45도에서 하나 더.
- **소리·빛**: 옷을 펴고 접는 소리, 서랍 여닫는 소리.
- **연결·대안**: 양말이 다 짝이 맞으면 찾는 장면은 만들지 않는다(연기하지 않는다). 그때는 장면 2의 ‘세제 어디 있어요?’가 한 번만 나와도 괜찮다.
- **꼭 말하고 싶은 내용**: 개서 정리한다, 다 끝났다.
- **촬영 후 직접 붙일 이야기**: 빨래 중 가장 귀찮은 일이나 좋아하는 일, 시청자에게 빨래를 어떻게 말리는지 물어볼 수 있다.

## 꼭 담을 대사·표현

정확한 원고는 촬영 전에 확정하지 않는다. 아래 문장은 화면과 실제 경험이 맞을 때만 쓰는 짧은 예시다. ‘반복’ 열은 위 반복 설계의 핵심 문장 중 그 장면에서 다시 들려줄 것이다.

| 장면 | 말하고 싶은 핵심 | 필요한 경우에만 정확한 문장 | 반복 | 화면에서 보여 줄 단서 |
|---|---|---|---|---|
| 1 시작 | 빨래가 많다 | “빨래가 많아요.” | 많아요 → (8) 다 끝났어요 | 가득 찬 바구니 |
| 2 세탁기 | 넣고 돌린다 | “세탁기에 넣어요.” | 어디 있어요 ① (있으면) | 넣는 손 → 세제 → 버튼 |
| 3 기다리기 | 다 됐다 | “다 됐어요.” | 다 됐어요 ① | 시간 표시 → 알림음 → 문 열기 |
| 4 나누기 | 건조기 vs 건조대 | “이건 건조기에 넣어요.” “이건 건조대에 널어요.” | 넣어요/널어요 (옷마다) | 들어 올린 옷 → 라벨 → 두 무더기 |
| 5 건조기 | 건조기 돌리기 | 실제에 맞게 직접 결정 | 넣어요 | 넣는 손 → 버튼 |
| 6 건조대 | 털어서 널기 | “아직 안 말랐어요.” | 널어요 (옷마다), 안 말랐어요 ① | 털기 → 걸기 → 젖은 건조대 와이드 |
| 7 걷기 | 다 마름 | “다 말랐어요.” “따뜻해요.” | 다 됐어요 ②③, 안 말랐어요 → 다 말랐어요 | 건조기 알림 → 같은 구도 마른 건조대 |
| 8 개기 | 개고 정리, 끝 | “이렇게 개요.” “양말 한 짝 어디 있어요?” “다 끝났어요.” | 개요 (옷마다), 어디 있어요 ②, 다 끝났어요 | 개는 손 → 양말 → 빈 바구니 |

## 촬영 체크리스트

- [ ] 빨래는 화면에 보여도 되는 옷만, 사적인 옷은 따로
- [ ] 장면마다 **동작 도중 컷**을 위한 두 크기 (문 닫기, 옷 털기, 접기, 쏟기)
- [ ] 장면마다 현장음 15초 (세탁기 물소리·탈수·알림음, 건조기, 옷 터는 소리, 서랍)
- [ ] 이동 방향: 세탁실 → 건조대/거실 왼→오
- [ ] 바구니가 처음부터 끝까지 같은 바구니로 이어지게
- [ ] **같은 구도 두 번**: 세탁기 시간 표시(여러 번), 건조대 젖은/마른 와이드, 바구니 가득/빈 와이드 — 삼각대 위치 테이프 표시
- [ ] 반복 장면용 옷별 클로즈업: 나누기 4–6벌, 널기 3–5벌, 개기 수건·티셔츠·바지·양말
- [ ] 같은 문장을 다시 말할 때마다 붙일 서로 다른 화면 확보
- [ ] 세탁기 표시창 반사, 베란다 역광, 실내 조명 색 확인
- [ ] 장면이 빠졌을 때 쓸 연결 컷: 바구니 들고 걷기, 돌아가는 세탁기·건조기 창, 창밖 빛, 털기 클로즈업

## 촬영 후

먼저 장면 연결표대로 이어 붙여 말 없이도 흐름이 보이는 6–8분 편집본을 만든다. 그 화면을 보며 촬영자가 직접 최종 대본을 쓴다. 세탁·건조 시간, 나누는 기준, 옷이 줄었는지 같은 내용은 실제 사실만 말한다. 후시녹음이 화면보다 길면 화면을 멈추기 전에 말을 줄이거나 관련 행동 화면으로 이어 간다. 완성 대본을 받은 뒤 전체 난이도를 범위로 검토하고 필요한 에셋만 따로 살핀다.
