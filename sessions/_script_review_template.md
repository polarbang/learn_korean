# S000 · 최종 대본 수준 검토

- **검토한 대본**: (파일명·버전)
- **전체 난이도 범위**: (예: A1–A2, A1–B1, A2–B1)
- **판단 근거**: (대본 전체의 문장 길이, 문법, 어휘와 맥락을 구체적인 대사로 설명)
- **B2 이상으로 느껴지는 부분**: (없으면 없음. 있으면 대사와 이유)
- **간단히 바꿀 수 있는 표현**: (원문 → 제안 → 이유. 실제 대본 수정은 촬영자가 선택)
- **영상 맥락이 뜻을 돕는 부분**: (영상이 없으면 촬영 계획에서 확인 가능한 범위만)
- **이해에 추가 화면·사진·아이콘이 필요한 부분**: (영상이 없으면 확인 필요로 표시)

단어장에 없는 말을 자동으로 어려운 단어로 판단하지 않는다. 단어별 등급을 확정하는 표가 아니라 영상 전체에 대한 판단을 기록한다.
