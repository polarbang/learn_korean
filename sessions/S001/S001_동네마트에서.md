# S001 · 동네 마트에서

- **레벨**: A1~A2
- **상황**: 주말에 동네 중형 마트에 가서 여러 가지를 사는 하루 (집 인트로 → 마트 입구 → 매장 → 계산 → 집 아웃트로)
